Frequently asked questions

How do I add a book?

Tap + in Library and pick an EPUB file from Files, iCloud Drive or any other location. Books with DRM (for example, most books bought from online bookstores) cannot be opened. The book is stored on your iPhone only.

How do I turn cloud features off (or on)?

Open Profile → Cloud features. When they are off, the assistant does not answer and the cloud voice is replaced by the built‑in iPhone voice; nothing is sent to the server. You can turn them back on at any time. Before the first cloud request the app shows exactly what is sent and where.

Why does it say the assistant is unavailable?

  • “Cloud features are off” — turn them on in Profile.
  • “No connection to the server” — the assistant and the cloud voice need an internet connection; the iPhone voice works offline.
  • “The assistant is busy right now. Try again in N s” — the server limits how many questions can be asked per minute; wait and try again.
  • “The assistant’s daily limit has been reached” — the shared daily budget for cloud answers is spent; it resets the next day.
  • “Speech recognition is unavailable” — allow the microphone and speech recognition in iOS Settings → Lama, or type the question instead.

If none of this helps, write to us with the exact message you see.

Частые вопросы

Как добавить книгу?

Нажмите + в Библиотеке и выберите файл EPUB из «Файлов», iCloud Drive или другого места. Книги с DRM (например, большинство купленных в онлайн‑магазинах) открыть нельзя. Книга хранится только на вашем iPhone.

Как отключить (или включить) облачные функции?

Откройте Профиль → Облачные функции. Когда они выключены, ассистент не отвечает, а облачный голос заменяется встроенным голосом iPhone; на сервер ничего не отправляется. Включить обратно можно в любой момент. Перед первым облачным запросом приложение показывает, что именно и куда отправляется.

Почему ассистент «недоступен»?

  • «Облачные функции выключены» — включите их в Профиле.
  • «Нет соединения с сервером» — ассистенту и облачному голосу нужен интернет; голос iPhone работает офлайн.
  • «Ассистент сейчас занят. Попробуйте через N с» — сервер ограничивает число вопросов в минуту; подождите и повторите.
  • «Дневной лимит ассистента исчерпан» — общий дневной бюджет облачных ответов израсходован; он обновляется на следующий день.
  • «Распознавание речи недоступно» — разрешите микрофон и распознавание речи в Настройках iOS → Лама или введите вопрос текстом.

Если ничего не помогло, напишите нам и приведите точный текст сообщения.
